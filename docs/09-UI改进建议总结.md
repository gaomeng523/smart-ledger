# UI 改进建议总结

| 项目 | 内容 |
| --- | --- |
| 文档类型 | UI 改进建议总结（基于截图评审 + 代码对照） |
| 文档版本 | V1.0 |
| 编制日期 | 2026-10-27 |
| 依据 | 2026-10-27 的四张截图（首页 / 降级表单 / 账单列表 / 我的）、当前 `miniprogram/` 代码、《07-小程序UI与交互设计》 |
| 目标 | 从「可爱但平均」推进到「实用、耐看、有层级」 |
| 范围 | 首页、记账表单、账单列表、我的、底部导航；统计与次级页沿用同一套令牌 |

> **一句话结论：** 不建议推倒重来。现有奶油底、萌萌、分类线图标都是好资产；真正要改的是**层级、形状、图标一致性、状态表达**，也就是把「奶油马卡龙」从糖果感推进到纸感——暂称「奶油手账 2.0」。

## 0. 执行摘要

### 0.1 最优先的 5 个改动

| # | 改动 | 当前问题 | 预期收益 |
| --- | --- | --- | --- |
| 1 | 首页去掉空输入时的大号米色「记账」条，改成输入卡内的圆形发送键 | 首屏最大色块是一块「像禁用」的米色，第一眼没有行动点 | 首屏立刻有焦点，页面显得更轻、更完整 |
| 2 | 记账表单改为「标签上置、错误下置、金额做 hero、保存吸底」 | 左标签占列 + 「待补充」在字段外，分类字段被挤窄，整行不对齐 | 字段等宽、扫描更快，表单不再像后台配置页 |
| 3 | 列表分组卡从 `bg-muted` 改成暖白 + 1px 描边（或整页白纸 + 日期分组） | 分组卡和页面底色几乎同色，层次糊在一起 | 列表更清晰，金额和日期头更好读 |
| 4 | 我的页统一线性图标 + 柔和色块，按「记账工具 / 数据与订阅 / 更多」分组 | 7 行里只有 2 个 emoji，其余纯文字，图标系统三种风格 | 页面从「设置列表」变成「个人页」 |
| 5 | tabBar 补 4 个线性图标 | 纯文字 tabBar + 底部大白带，是整套 UI 最「没做完」的地方 | 完成度提升最明显，改动成本最低 |

### 0.2 设计方向

- **关键词：** 奶油纸感、墨色文字、松绿主色、陶土红支出、线性图标、少胶囊。
- **保留：** 奶油底、萌萌、分类线图标、骨架屏/空态/错误态、文案性格（「吃掉账单烦恼」）。
- **不再做：** 更多渐变、所有东西都是胶囊、emoji 当结构图标、每块内容都套白卡、只靠红绿表达语义。

### 0.3 工作量预估

核心 4 页（首页、表单、列表、我的）+ tabBar：约 **2~3 天**；统计与 6 个次级页对齐：再加 **1~2 天**。主要是 WXSS + WXML 结构调整，**后端接口不动**。

## 2. 设计方向：奶油手账 2.0

### 2.1 三条原则

1. **一屏一个重点。** 首页是发送键，列表是当前 tab，表单是保存键，我的页是萌萌。绿色不再到处出现。
2. **形状按功能分级。** 卡片 16px、输入 10px、按钮 12px，只有标签/分段用 999 胶囊；不再「万物皆胶囊」。
3. **图标一套到底。** 线性图标 + 柔和色块；emoji 只用于文案情绪，不做结构图标。

### 2.2 色板（建议值，均验算过对比度）

| 角色 | 当前 | 建议 | 说明 |
| --- | --- | --- | --- |
| 页面底 | `#FFF9F2` | `#F6F1E8` | 更像纸，白卡能浮起来 |
| 卡片 | `#FFFFFF` | `#FFFDF9` | 暖白，不刺眼 |
| 主文字 | `#1A1A1A` | `#2A2520` | 暖墨色，13.5:1 |
| 次要 | `#666666` | `#6E6459` | 5.7:1 |
| 弱化 | `#6B6B6B` | `#72685D` | 4.8:1，别再低 |
| 主色 | `#07C160` / `#048030` | `#1F6B4A` | 松绿，白字 6.4:1 |
| 支出文字 | `#D03D3A` | `#A94839` | 陶土红，5.6:1 |
| 支出装饰 | `#FF7B84` | `#C85C4A` | 只做柱状图、圆点、图标 |
| 点缀 | `#FFC46B` 等 | `#F3D9A4` / `#F2D3CE` / `#CFE8DA` | 只做底色，上面放墨色图标 |
| 分割线 | `#F0E6DC` | `#E9DFD2` | 1px，能看见但不抢 |
| 卡片阴影 | 粉色 `.16` | `rgba(74,53,42,.06)` | 中性暖影，去掉粉色光晕 |

> 如果不想动品牌绿，**可以保留当前 `#048030`**，只做布局、形状、图标和层级调整；上面是「更不像微信原生控件、更像自有品牌」的可选方案。

### 2.3 字体、间距、圆角

| 项 | 建议 |
| --- | --- |
| 金额 hero | 56~64rpx / 600 |
| 页面标题 | 40rpx / 600 |
| 区块标题 | 32rpx / 600 |
| 正文 | 28rpx / 400 |
| 次要 | 24rpx / 400 |
| 弱化 | 22~24rpx（只用于版本号等非关键信息） |
| 按钮 | 30~32rpx / 600 |
| 页面左右边距 | 40rpx（20px），比现在的 32rpx 更透气 |
| 卡片内边距 | 32rpx |
| 卡片圆角 | 32rpx |
| 输入框圆角 | 20rpx |
| 按钮圆角 | 24rpx（不再是胶囊） |
| 标签/分段 | 999rpx |

### 2.4 保留与舍弃

| 保留 | 舍弃/收敛 |
| --- | --- |
| 奶油底、暖色 | 所有卡片同粉色阴影 |
| 萌萌的 8 个状态与「吃掉烦恼」 | 首页 48px 的小萌萌角标（改为 64~72px 或放到问候区） |
| 分类线性图标 | 按 index 轮换的分类底色 |
| 骨架屏、空态、错误态 | 「失败 = 空」的旧逻辑（已改善，继续保持） |
| 文案性格 | 「语音 · V2」「按分类筛选 · V2 开放」这类过期文案 |

## 3. 页面改法

### 3.1 首页：从「表单」变成「一句话入口」

```text
┌──────────────────────────────┐
│ 晚上好                  (萌萌)│
│ 10月27日 周二 · 今天记了 2 笔 │
│ ┌──────────────────────────┐ │
│ │ 例如：今天微信买菜 100 元…│ │
│ │ [相机]  0/200        (→) │ │
│ └──────────────────────────┘ │
│ 常用  [早餐 15] [打车 28] …  │
│ ┌──────────────────────────┐ │
│ │ 10月支出 ¥300.00   统计 ›│ │
│ │ 收入 ¥0.00 · 结余 ¥300.00│ │
│ └──────────────────────────┘ │
│ 最近账单              全部 › │
│ ○ 买菜食材        -200.00    │
│ ○ 药品            -100.00    │
└──────────────────────────────┘
```

**改法：**

1. **去掉整条米色 CTA**，输入卡右下角放 44px 圆形发送键。空态是浅薄荷底 + 松绿箭头，有文字时变松绿底 + 白箭头；不再出现「一块像禁用的色板」。
2. **输入卡从 174px 收到 120~140px**，`auto-height` 最多长到 4 行；顶部加「晚上好 + 日期 + 今天记了 N 笔」，填掉现在的顶部空白。
3. **拍照移进卡片**，语音在功能上线前隐藏；`0/200` 只在有输入时出现。
4. **模板改成「常用」胶囊**，放在输入卡下方，点一下直接记一笔（带撤销），比现在的模板横条更顺手。
5. **本月统计改成一条「月报条」**：支出是主数字（24px），收入/结余是次要信息（14px），右侧「统计 ›」。不要再做成三行表格。
6. **最近账单**保留，把「更多」改成「全部」，行高略降，给底部留出空间。

### 3.2 记账表单：从「米色格子」变成「金额优先」

```text
──────── 手动记账 ────────
        ¥ 101.00
     [ 支出 ] [ 收入 ]
渠道   微信                 ›
分类   请选择               ›
       ! 请选择分类
日期   2026-10-27           ›
标签   + 添加标签
备注   选填…
──────────────────────────
[ 保存 ]   保存并再记一笔
```

**改法：**

1. **标签上置、字段等宽**：现在左边 110rpx 的标签列 + 字段外的「待补充」，让分类字段明显窄一截；改成 label 在上、错误信息在下，所有字段同宽。
2. **金额做 hero**：32px、600、下划线输入，不要米色盒子；类型用两段式控件（选中白底 + 松绿文字，或松绿底 + 白字，二选一）。
3. **渠道/分类/日期用「图标 + 值 + 箭头」的行**，高度 52px，分隔线内缩；比一排米色框更轻、更像工具。
4. **标签/备注收进「更多」或折叠**：金额、类型、分类、渠道、日期是必填；标签和备注默认收起，减少表单长度。
5. **底部 sticky 保存**：保存 52px 松绿，旁边「保存并再记一笔」；键盘弹起时按钮不被遮住。
6. **表单容器统一**：现在降级表单是首页内联长卡，识别预览是半屏弹窗；建议都用**半屏 sheet + 吸底按钮**，或者都改成整页，不要混着来。

### 3.3 账单列表：从「卡片堆」变成「账本页」

```text
[搜索备注、分类、金额]   [筛选 2]
2026年10月 ⌄
全部    支出    收入
──────────────────────────
10月27日 周二        支出 ¥300
┌──────────────────────────┐
│ [图标] 买菜食材   -200.00 │
│        支付宝 · 菜市场    │
│ [图标] 药品       -100.00 │
│        微信               │
└──────────────────────────┘
本月 2 笔 · 支出 ¥300.00
[ 再记一笔 ]
```

**改法：**

1. 搜索框加放大镜图标；筛选改成「漏斗 + 数量角标」，有筛选时变松绿。
2. 月份从胶囊改成**大标题 + 下拉箭头**；收支筛选从绿色胶囊改成**下划线 tab**，当前项松绿文字 + 2px 下划线。
3. 分组卡用暖白 + 1px 描边，日期头加一个小圆点或左侧色条；或者干脆去掉分组卡，用整页白纸 + 日期分组，更像账本。
4. 行内图标按分类固定颜色（食物奶黄、医疗浅粉、交通浅蓝），不要按 index 轮换。
5. 底部「已加载全部」换成**本月汇总条**：「本月 2 笔 · 支出 ¥300.00」+「再记一笔」。现在列表只有两条时，下面一大片空白很浪费。
6. 空态/错误态已经有，保留；错误态用 `offline` 萌萌 + 重新加载。

### 3.4 我的：从「设置列表」变成「个人页」

```text
┌──────────────────────────┐
│ (萌萌头像) 微信用户       │
│ 本月 2 笔 · 支出 ¥300.00  │
└──────────────────────────┘
记账工具
  [模板] 模板管理      3 个 ›
  [预算] 预算设置      80%  ›
  [别名] 别名词典      12 条 ›
数据与订阅
  [订阅] 订阅管理      2 个 ›
  [导入] 账单导入           ›
  [导出] 数据导出           ›
更多
  [心愿] 心愿储蓄      2 个 ›
  关于萌萌 / v1.0.0
```

**改法：**

1. **顶部做成资料卡**：萌萌头像放白色圆环里，昵称、本月摘要一行；不要现在这种「大头像 + 两行字 + 大片奶油」的悬空感。
2. **分组**：记账工具 / 数据与订阅 / 更多；每段一个小标题，行高 56px。
3. **每行统一 36px 柔和色块 + 线性图标**，去掉 emoji；右侧放「3 个 / 80% / 12 条」这种有用信息，比现在的「一键记常用账」提示更有价值。
4. 版本号和「关于萌萌」放底部，弱化。

### 3.5 底部导航

1. 4 个 24px 线性图标：记一笔（笔/本）、账单（清单）、统计（柱状图）、我的（人）。
2. 选中松绿 `#1F6B4A`，未选中 `#72685D`；标签 10~11px；背景 `#FFFDF9` + 顶部 1px 线。
3. 优先用微信原生 tabBar（81×81 PNG，普通/选中两张）；如果想做选中胶囊/中间凸起，再上 custom tabBar。
4. 现在的纯文字 tabBar 是「完成度」问题，不是审美问题，补上图标立刻不一样。

### 3.6 统计与次级页

- 统计页沿用同一套令牌：结余主数字 56~64rpx，趋势图用松绿/陶土红，分类列表用固定分类色。
- 模板、预算、导入、别名、心愿储蓄、订阅等次级页只做「令牌 + 列表行 + 空态」三件事，不单独发明新样式。

## 4. 实施顺序

| 阶段 | 内容 | 预估 | 产出 |
| --- | --- | --- | --- |
| Phase 0 | 设计令牌、圆角/阴影/字号、按钮/输入框/卡片基础样式、tabBar 图标 | 0.5 天 | 全局样式与 4 个 tab 图标 |
| Phase 1 | 首页 + 记账表单 sheet（核心闭环，决定 80% 第一印象） | 1 天 | 新首页、新表单 |
| Phase 2 | 账单列表 + 搜索/筛选/分组/底部汇总 | 1 天 | 新列表页 |
| Phase 3 | 我的页 + 分组/图标/资料卡 | 0.5 天 | 新我的页 |
| Phase 4 | 统计页与 6 个次级页对齐 | 1~2 天 | 全站一致 |

**改动范围：** 主要是 WXSS + 部分 WXML 结构，业务逻辑和后端接口不动。首页发送键需要加一个输入态判断；列表底部汇总需要前端按已加载数据算；tabBar 需要图标资源或 custom tabBar。

**建议节奏：** 先做 Phase 0 + 首页 + tabBar，这三件就能看出方向对不对，再决定要不要铺到其他页。

## 5. 验收清单

- [ ] 正文/次要文字对比度 ≥ 4.5:1，大字号 ≥ 3:1；点缀色不承载信息文字。
- [ ] 所有可点元素 ≥ 88rpx（44px），文本按钮用 padding/伪元素扩大热区。
- [ ] 一屏只保留 1 个高饱和重点；绿色不再同时出现在标签、按钮、分段、金额上。
- [ ] 图标统一为线性风格（1.8 描边、圆角端点），不再混用 emoji 与实心图标。
- [ ] 关键字号不小于 24rpx；不再出现 20rpx 的月份轴、标签。
- [ ] 加载、空态、错误态三态齐全；错误态可重试，不伪装成「没有数据」。
- [ ] 所有颜色/圆角/阴影来自令牌；页面里没有新的十六进制色值和随手圆角。
- [ ] 首屏不滚动就能看到主行动；键盘弹起时保存按钮不被遮住。
- [ ] iPhone SE / 13 / Pro Max 与 Android 主流机型各过一遍；tabBar 图标不糊。
- [ ] 首页冷启动到可输入 ≤ 1s；列表滚动无明显掉帧。

## 6. 待确认

1. **风格选 A 还是 B？**
   - **A. 奶油手账 2.0（推荐）**：保留奶油和萌萌，加入纸感、松绿、陶土红、线性图标，适合「个人记账」的温度。
   - **B. 清爽现代**：白底、墨黑、单一绿色、无卡片阴影、数据优先；更像工具，但会丢掉一部分可爱感。
2. **tabBar 用原生还是 custom？** 原生 + 81×81 PNG 更稳；custom 可以精确控制选中态/凸起，但要多写一个组件并处理 `switchTab`。
3. **这次铺多大范围？** 只做首页 + 表单 + tabBar，还是四页一起？建议先做三件看方向。
4. **品牌绿保留还是换松绿？** 如果怕改动太大，可保留 `#048030`，只改布局、圆角、图标与层级。
5. **下一步要静态稿还是直接改代码？** 静态稿适合先确认方向；直接改代码适合已经确定要落地。
